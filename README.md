# 🎬 Claude & Human 3D Viral Shorts Engine
> **Make viral animated 9:16 shorts and reels 100% free with 3D character models, AI dialogue, and auto-synced kinetic subtitles.**

---

## 🌟 Features
* **🎭 3D Animated Character Models**:
  * **Human Model**: Shaded hoodie, expressive face, natural eye blinking, anatomical mouth with phoneme lip-sync, and studio condenser microphone.
  * **Claude AI Model**: Sculpted matte-black cyber-android chassis with glowing Anthropic orange conduits, 8-point spark chest reactor, digital visor with laser scan line, frequency-modulated audio equalizer mouth, and anti-gravity hover physics.
* **📱 Vertical 9:16 Shorts & Reels**: 1080×1920 at 60 FPS hardware-accelerated export.
* **✍️ Viral Retention Pacing**: Built-in 0–2s crazy hooks, rapid-fire banter, punchlines, and seamless audio loops.
* **📝 Kinetic Word-by-Word Subtitles**: Hormozi / Zack D. Films style bold yellow highlights (`#FACC15`) with heavy black stroke outlines.
* **🔊 Procedural Audio & Foley**: Built-in transition whooshes, text pop sounds, and ambient tension synth drone without needing external sound packs.
* **🍏 Cross-Platform Skill Support**: Includes a ready-to-use Antigravity & Claude Code skill file (`SKILL.md`) for instant macOS, Windows, and Linux setup.

## 🚀 Quick Start

### 1. Run the Browser Studio (Zero Setup)
Simply open `index.html` in your favorite web browser (Chrome, Safari, Edge, Brave):
```bash
# macOS
open index.html

# Windows
start index.html
```
* Pick a template (e.g. *$1 Bank Loophole*, *1.25M Miles Pudding Guy*, *Simulation Glitch*).
* Choose your layout (**Podcast Duet Split** or **Facing 3D Arena**).
* Click **▶️ Preview Video** to watch the characters talk.
* Click **🔴 Export Full HD 9:16 Video** to download the finished video!

---

### 2. Python CLI Generator
Generate stories from the terminal:
```bash
# List pre-built viral stories
python make_video.py --list

# Generate from any custom idea
python make_video.py -t "The Secret Gold Vault of Fort Knox"
```

## 🍎 Install as a Global Skill on macOS

To generate shorts on any Mac without copying this repository:

1. Run the installer:
   ```bash
   bash install_mac.sh
   ```
2. Or copy `SKILL.md` to your skills folder:
   ```bash
   mkdir -p ~/.gemini/config/skills/claude-human-shorts
   cp SKILL.md ~/.gemini/config/skills/claude-human-shorts/
   ```
3. Open Antigravity or Claude Code on your Mac and say:
   > *"Make a viral 3D Claude & Human short about the man who bought a bank for $1 and open the studio."*
